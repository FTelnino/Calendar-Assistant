# Calendar Assistant (n8n + AI Agent)

An AI agent built in n8n that manages calendar tasks and sends emails from natural-language chat messages.

## How it works
1. Chat message triggers the workflow
2. AI Agent (Groq LLM) decides what to do
3. Calendar and Gmail tools carry out the action

## Tech
n8n · Groq · Google Calendar · Gmail

## Run it yourself
1. Install n8n: `npx n8n`
2. Import `Calendar Assistant.json`
3. Add your own Groq, Google Calendar and Gmail credentials
